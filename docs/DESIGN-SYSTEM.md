## 2. Design System (UI-UX-Pro-Max Recommended)

### Pattern: Enterprise Gateway
- Hero with video/mission statement
- Solutions by Industry
- Client logos/testimonials
- Contact Sales CTA
- **Best for**: B2B enterprise, corporate, trustworthy

### Style: Accessible & Ethical
- High contrast, large text (16px+)
- Keyboard navigation, screen reader friendly
- WCAG compliant, focus states, semantic HTML
- **Best for**: Healthcare, medical, pharma, inclusive products

### Color Palette (Medical Professional)
| Token | Color | Usage |
|-------|-------|-------|
| Primary | #2563EB | Brand blue, trust, professionalism |
| Secondary | #3B82F6 | Accent blue, interactive elements |

| Text | #1E293B | Dark slate, body text |
| Success | #10B981 | Green, positive actions |
| Muted | #64748B | Gray, secondary text |
| Border | #E2E8F0 | Light gray, dividers |

### Typography
- **Primary**: Figtree (Headings, UI)
- **Secondary**: Noto Sans (Body, Multilingual)
- **Google Fonts**: https://fonts.google.com/share?selection.family=Figtree:wght@300;400;500;600;700|Noto+Sans:wght@300;400;500;700

### Key Effects
- Clear focus rings (3-4px)
- ARIA labels for accessibility
- Skip links for keyboard nav
- Responsive design (mobile-first)
- Reduced motion support
- 44x44px touch targets

## 5. Multilingual Strategy

### Phase 1: Chinese + English
- Default: English (international)
- Language switcher: EN | 中文
- Both languages fully supported

### Phase 2: Additional Languages
- Arabic (RTL support) - Middle East market
- Russian - Central Asia market
- French - Africa market
- Spanish - Americas market

### Implementation
- Next.js i18n with next-intl
- URL structure: /en/... , /zh/...
- Hreflang tags for SEO
- RTL layout support for Arabic

## 6. Technical Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Language**: TypeScript 5
- **Icons**: Lucide React (SVG, not emoji)
- **Fonts**: Figtree + Noto Sans (Google Fonts)
- **Deployment**: Vercel
- **Domain**: www.0539cn.us
- **Analytics**: Google Analytics 4
- **Chat**: WhatsApp Business API

---

## 7. Anti-Patterns to Avoid

- ❌ No emojis as icons (use SVG)
- ❌ No low contrast text
- ❌ No horizontal scroll on mobile
- ❌ No layout shifts (CLS)
- ❌ No disabled zoom
- ❌ No hover-only interactions
- ❌ No animations > 500ms
- ❌ No hardcoded colors (use tokens)

---

## 8. Pre-Delivery Checklist

- [ ] No emojis as icons (use Lucide SVG)
- [ ] cursor-pointer on all clickable elements
- [ ] Hover states with smooth transitions (150-300ms)
- [ ] Light mode: text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard nav
- [ ] prefers-reduced-motion respected
- [ ] Responsive: 375px, 768px, 1024px, 1440px
- [ ] WhatsApp CTA prominent on all pages
- [ ] Language switcher functional
- [ ] All text in English (Phase 1)
